Build recipe: glowing bulb
  1. Add battery, switch, resistor and LED/bulb.
  2. Turn Connect parts ON.
  3. Tap parts in sequence to make a loop, including the final return connection to the battery.
  4. Run circuit. Toggle the switch to test ON/OFF.
